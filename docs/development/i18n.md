# Web i18n architecture

The Web application uses `i18next` with `react-i18next`. Initialization lives in
`apps/web/src/i18n/index.ts`; namespace resources live under
`apps/web/src/i18n/locales/{en,zh-CN}`. English is the fallback locale.

Locale detection prefers the validated `proxyhub.locale` local-storage value, then browser
languages, and finally English. Storage and DOM access are guarded so SSR, tests, privacy modes,
and disabled storage do not crash initialization.

Use `useTranslation` in React components. Never translate API error codes; map a stable code to the
`errors` namespace. Use the shared `Intl` formatters for user-facing dates and numbers.
