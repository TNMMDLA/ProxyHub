# Subscriptions

A subscription binds one Policy to Mihomo, sing-box, or Raw VLESS. Creation and updates run a
server-side dependency and compiler preflight immediately before persistence. Blocking dependency
failures do not rotate the token, update access time, or save the mutation.

Run Readiness, Sanitized Preview, and Response Test from the subscription card. Public tokens are
shown only when created or rotated. Store the URL securely; ProxyHub stores only a hash.
