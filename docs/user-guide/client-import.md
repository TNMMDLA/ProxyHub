# Client Import

Use the format that matches the client:

- Clash Verge Rev and Mihomo Party: Mihomo subscription URL.
- sing-box GUI: sing-box subscription URL.
- v2rayN and v2rayNG: Raw VLESS subscription or the controlled single-node share URI.

Raw VLESS does not carry Policy routing or Rule Sets. Client UI labels can differ between releases.
The capability matrix in Subscriptions is generated from compiler metadata and is the source of
truth for supported features. Real Mihomo and sing-box GUI import verification remains pending.
